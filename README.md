# 🎛️ Calculator App

✨ A simple and interactive **Calculator Web App** built using HTML, CSS, and JavaScript.  
Perform basic arithmetic operations like addition, subtraction, multiplication, and division with a clean and responsive interface.

---

## ✨ Features

🔢 Basic Arithmetic Operations (`+`, `-`, `×`, `÷`)  
🧹 Clear Input (`C`) 
📱 Responsive Design for Mobile & Desktop  
🎨 Interactive Button Animations  
🕘 Lightweight and Fast  

---

## 🛠️ Technologies Used

* HTML5  
* CSS3 (Flexbox, Grid, Transitions)  
* JavaScript (DOM Manipulation & Event Handling)

## ⚙️ How to Run

1. Download or clone the project  
2. Open the project folder  
3. Open `index.html` in your browser  
4. Start calculating 🔢

---

## 🎯 How It Works

👉 Click **Numbers** → Input values  

👉 Click **Operators (+ - × ÷)** → Select operation  

👉 Click **=** → Shows result  

👉 Click **AC** → Clears all input
